# Инструкция для человека: установка в выбранный каталог

Начните с этой страницы по ссылке из выбранного релиза. Используйте инструкции
и файлы именно его версии. Для установки через ИИ передайте ему ссылку на
[agent.md](agent.md) этого же релиза: агент сначала читает её в браузере.

Нужна текущая обезличенная офлайн-поставка с установщиком. Архив и SHA256
скачиваются заранее через разрешённый канал.
На сервере ничего скачивать или устанавливать из репозиториев пакетов не нужно.
strace не требуется: он используется только на машине испытаний. Встроенные
внешние транспорты исключены из этой сборки; ограничения и аудит описаны в
[OFFLINE-AUDIT.md](OFFLINE-AUDIT.md).

## Входные значения

Оператор задаёт значения; при работе через агента — в своём поручении ему.
Значения ниже — обозначения,
а не готовые пути. TARGET может быть любым абсолютным новым/пустым каталогом,
доступным без sudo. SOURCE — отдельно распакованная поставка, не TARGET.

```sh
SOURCE='абсолютный путь распакованной поставки'
TARGET='абсолютный путь установки, выбранный пользователем'
PYTHON='полный путь установленного Python 3.9 или новее'
PORT='выбранный внешний порт'
BACKEND_PORT='другой выбранный внутренний порт'
PUBLIC_URL='выбранный HTTP(S) origin без пути'
ADMIN_USER='выбранное имя администратора'
PLAN='полный путь нового файла плана вне TARGET'
```

Пробелы, кириллица, `%` и `$` в каталогах поддерживаются. Имя пользователя,
домашний каталог, диск и корень размещения проектов не предполагаются кодом.

## Проверка и план

После проверки SHA256 архива и отдельной распаковки:

```sh
"$PYTHON" -I -B "$SOURCE/tools/verify_payload.py"
"$PYTHON" -I -B "$SOURCE/tools/collect_environment.py"
"$PYTHON" -I -B "$SOURCE/tools/install.py" plan \
  --target "$TARGET" \
  --port "$PORT" --backend-port "$BACKEND_PORT" \
  --public-url "$PUBLIC_URL" --admin-user "$ADMIN_USER" \
  --output "$PLAN"
```

По умолчанию внешний вход слушает loopback. Для явно разрешённого LAN-входа
добавить `--listen-host` с выбранным IP. При HTTPS корпоративный TLS-прокси
должен быть подготовлен отдельно.

Plan проверяет реальную временную systemd user-unit с PrivateUsers/PrivateNetwork
и seccomp-фильтр. Если ограничения ОС это запрещают, установка останавливается.
Менять политики или ослаблять профиль ради запуска нельзя.

`--no-start` добавляется к plan, если нужны только файлы/unit без запуска.
`--enable` — явный выбор автозапуска после login. Linger не изменяется.
Короткий socket-путь выбирается в XDG_RUNTIME_DIR независимо от длины TARGET;
при необходимости можно задать отдельный короткий `--runtime-dir`.

## Применение

Проверьте сводку и SHA плана. Если установка с этими параметрами уже поручена,
дополнительное подтверждение не нужно. Иначе согласуйте конкретный готовый план.

```sh
PLAN_SHA256='значение PLAN_SHA256 из предыдущей команды'
"$PYTHON" -I -B "$SOURCE/tools/install.py" apply \
  --plan "$PLAN" --sha256 "$PLAN_SHA256"
"$PYTHON" -I -B "$TARGET/tools/install.py" status --target "$TARGET"
```

План/payload перепроверяются перед применением. Существующая установка и чужие
службы не заменяются. Сгенерированный config хранит все выбранные пути, unit
экранируются установщиком; ручная замена каталогов в шаблонах не требуется.
User-unit используют XDG_CONFIG_HOME — стандартную инфраструктуру systemd,
а не фиксированный путь самого приложения.

## Управление

```sh
"$PYTHON" -I -B "$TARGET/tools/install.py" status --target "$TARGET"
"$PYTHON" -I -B "$TARGET/tools/install.py" stop --target "$TARGET"
"$PYTHON" -I -B "$TARGET/tools/install.py" start --target "$TARGET"
```

Данные хранятся в TARGET/data. Начальный пароль — в data/initial-credentials.json,
права 0600; не публикуйте его. Уже установленный TARGET нельзя просто переместить:
его config и unit содержат выбранные при установке абсолютные пути. Для переноса
нужен новый план; изменения исходников проекта для другого TARGET не требуются.
Автоматическое обновление/миграция в этой версии не реализованы.

START_OK подтверждает локальный HTTP, issuer и CSP. Вход, заметки, OAuth/MCP,
перезапуск и внешний HTTPS проверяются дополнительно по agent.md.
