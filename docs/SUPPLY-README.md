# Документация текущей поставки

Актуальные файлы: [INSTALL.md](../INSTALL.md) и [agent.md](../agent.md).
Переносимый установщик: `tools/install.py`, команды `plan`, `apply`,
`preflight`, `start`, `stop`, `status`.

Каталог установки, выбранный пользователем, передаётся как `--target`.
Пути интерпретатора, unit, данных и Unix-сокета вычисляются для конкретного
сервера. Для другого каталога исходники не меняются. Непустой TARGET не заменяется.

Текущий релиз: `offline-no-egress-20261110`. Он включает MIT-лицензию
обвязки, исходные уведомления SilverBullet и лицензии компонентов.
Старые поставки удалены из общедоступного проекта.
